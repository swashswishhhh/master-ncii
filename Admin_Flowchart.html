🛡️ ServerMasterNCII — Admin Side Flowchart

Complete navigation map, button reference, and data model for the admin panel.

1. Login → Admin Routing

After authentication, the app checks users/{uid}.role in Firestore to decide where to navigate.

flowchart TD A["LoginActivity"] -->|"Google / Facebook / Guest"| B{"Check Firestore users doc role"} B -->|"role == admin"| C["AdminDashboardActivity"] B -->|"role == student or null"| D["MainActivity — Student Side"] B -->|"Guest user"| D B -->|"No user doc"| E["Create doc role=student"] --> D
⚠ Important: Admin access requires manually setting role: "admin" in Firestore Console under users/{uid}.

FieldDescription

Step 2 — Add Questions

ButtonAction
btnAddQuestionValidates form → adds to batch → shows chip (Q1, Q2…)

Step 3 — Review & Publish

Displays summary: Chapter, Title, Mission ID, Difficulty, Question count.

Firestore write order: Mission doc → Chapter subcollection entry → Batch-write all questions.
